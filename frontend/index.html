API Docs ↗

A Django REST API with a demo client. A Celery task collects readings for Egypt's 27 governorate capitals from Open-Meteo every hour into Postgres. JWT auth protects the write and AI endpoints, and Gemini turns real data into insights, forecasts and answers. The AI never invents numbers. The scheduled worker runs locally and in Docker, not on this free-tier host, so the readings shown here come from its last run.
